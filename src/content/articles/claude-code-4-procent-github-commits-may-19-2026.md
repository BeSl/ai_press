Свежий независимый анализ публичных репозиториев GitHub показал, что **около 4% всех публичных коммитов в мире за апрель–май 2026 года были автор��зованы Claude Code** — агентным CLI и GitHub-интеграцией от Anthropic. Месяцем ранее показатель составлял около 2%. Цифру привёл VentureBeat в материале о смене лидера в корпоративном AI и она же фигурирует в комментариях к майскому Ramp AI Index.

## Что именно меряется

Метрика считается по подписи коммитов и по сигнатурам автора (`Co-Authored-By: Claude`), которые Claude Code добавляет по умолчанию при работе через `claude -p` и через официальный GitHub Action. Это даёт нижнюю границу: реальная доля кода, написанного агентом и закоммиченного человеком без подписи, заведомо выше. Но даже эта осторожная оценка фиксирует беспрецедентный темп проникновения.

Для сравнения: ни одна другая агентная среда — ни Codex от OpenAI, ни Cursor, ни Devin, ни локальные обвязки на open-weights моделях — пока не оставляет видимого статистического следа в общем потоке публичных коммитов. Claude Code — единственный агент, у которого сегодня есть измеримая доля рынка на уровне всей экосистемы GitHub.

## Почему именно Claude Code

Триггеров три. Первый — синхронизация с workflow: Claude Code не предлагает альтернативный UI, а живёт внутри терминала и CI-пайплайна разработчика. Второй — качество моделей семейства Claude Opus 4.x на длинных задачах: на агентных бенчмарках вроде SWE-bench Verified Opus 4.7 с большим отрывом держит первое место. Третий — экономика: до 15 июня агентные пайплайны на Claude можно было запускать поверх подписки Pro/Max, что фактически субсидировало эксперименты сообщества.

Именно последний фактор Anthropic и закрывает с 15 июня введением отдельного кредитного пула на SDK (см. материал от 18 мая). Но 4% уже зафиксированы — даже если темп роста после 15 июня замедлится, сообщество разработчиков, которое привыкло работать через Claude Code, останется.

## Как это связано с обгоном OpenAI

Майский Ramp AI Index показал, что Anthropic впервые обогнала OpenAI в B2B-сегменте: 34,4% против 32,3%. Доля GitHub-коммитов — это в каком-то смысле leading indicator для следующего цикла индекса: разработчики, которые сегодня запустили Claude Code на пет-проекте, через 2–3 месяца приносят его в рабочий контур, через 6 — формируют корпоративную лицензию.

Если темп удвоения сохранится хотя бы один цикл, к июлю 2026-го Claude Code будет писать около 8% всех публичных коммитов мира. Это уже уровень, на котором GitHub-сама вынуждена встраивать поддержку «AI-авторства» в свои продуктовые поверхности — от Pulse и Insights до Copilot Enterprise.

## Что это значит для рынка

Для OpenAI это сигнал: проигрыш в B2B-индексе — не разовая флуктуация, а отражение фундаментального сдвига в инструментарии разработчика. Codex и GPT-5.5 Codex отвечают только частично: пока у OpenAI нет аналогичной CLI-обвязки с такой же глубиной интеграции в git.

Для Anthropic — стимул удержать темп до Google I/O и до релиза Mythos в июне. Если Google сегодня покажет конкурентоспособный агентный coding-стек на базе Gemini 4, доля Claude Code в коммитах может перестать расти геометрически.

Для open-weights коммьюнити — повод запросить совместимый интерфейс. Четыре китайские лаборатории, выпустившие на прошлой неделе open-weights coding-модели уровня Claude Opus 4.7 по трети цены, уже работают над CLI, эмулирующим протокол Claude Code: если им удастся повторить интерфейс при сопоставимом качестве модели, к концу 2026-го «4% коммитов от Claude» легко может стать «10% коммитов от агентов в принципе».

## Что смотреть дальше

Ближайшие контрольные точки — итоги кейноута Google I/O 19 мая (агентный coding-стек и интеграция с GitHub через Cloud Build), реакция OpenAI в виде анонса Codex 2 или нового тарифа для разработчиков, и публикация GitHub собственной статистики по AI-авторству, которую компания обещала к концу второго квартала.
