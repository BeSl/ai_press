Anthropic 11 мая 2026 года представила Claude Platform на AWS — корпоративный канал доступа к своему полному стеку моделей и инструментов прямо через инфраструктуру Amazon Web Services. Авторизация, биллинг и retirement коммитов AWS — всё на стороне облака. API и фичи — те же, что и в прямом Anthropic.

## Что внутри платформы

Поставка получилась широкой. Управляемые агенты (managed agents) с возможностью координировать суб-агентов, исполнение кода, веб-инструменты, "skills" — переиспользуемые навыки, prompt caching для снижения стоимости длинных контекстов, а также три модели текущего поколения: Claude Opus 4.7, Sonnet 4.6 и Haiku 4.5.

Anthropic делает ставку на корпоративный сегмент: компаниям, у которых есть значимые обязательства перед AWS и которые не хотят отдельно настраивать биллинг и compliance, теперь не нужно выбирать между удобством облака и фичами Claude. Они получают и то, и другое в одном окне.

## Контекст: гонка за корпоративного клиента

Релиз идёт параллельно с двумя другими ходами Anthropic на той же неделе. Во-первых, компания объявила совместное предприятие на $1,5 млрд с Blackstone, Goldman Sachs и General Atlantic для развёртывания Claude в их портфельных компаниях. Во-вторых, юридическая вертикаль получила больше 20 новых интеграций, включая кросс-интеграцию с Microsoft 365 и 12 ролевых плагинов для разных юридических специальностей.

OpenAI на той же неделе запустил OpenAI Deployment Co. с инвестицией более $4 млрд и анонсировал поглощение консалтинга Tomoro. Оба лидера рынка одновременно поняли простую вещь: барьер сейчас не в качестве моделей, а в том, как их довести до прода в больших организациях.

## Что это значит для пользователей AWS

Прямо: модели Claude можно вызывать как часть привычного облачного стека, не выходя за периметр AWS. Косвенно: для компаний, у которых compliance-команда уже одобрила AWS, появление полноценного Claude-стека снимает один из последних аргументов «давайте подождём».

Это не первый раз, когда Anthropic появляется на AWS — Bedrock уже несколько лет предоставляет Claude через Amazon. Новизна Claude Platform в том, что это полный паритет фичей с прямым API, включая агентов, навыки и code execution, а не урезанный набор.
