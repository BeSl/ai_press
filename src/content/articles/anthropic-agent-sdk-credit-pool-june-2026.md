Anthropic объявил о пересборке экономики подписок Claude. С 15 июня 2026 года Claude Agent SDK — включая команду `claude -p`, GitHub Actions для Claude Code и любые сторонние приложения, авторизующиеся через подписку пользователя, — выводится из общего пула лимитов и переводится на отдельный ежемесячный кредит. Размер кредита: $20 для Pro, $100 для Max 5x, $200 для Max 20x, $100 на место для Team, $200 на место для Enterprise. Кредит не накапливается между месяцами; превышение либо включается явно через биллинг API, либо приводит к приостановке SDK-запросов до начала следующего месяца.

## Что именно изменилось

До 15 июня токены, расходуемые SDK, шли в тот же лимит, что и интерактивные сообщения в ChatGPT-подобном клиенте Claude. Это создавало системную дыру: часть подписчиков платили $20–200 в месяц по тарифам Pro и Max, но запускали поверх своих подписок автономные агенты — OpenClaw и аналоги, — которые сжигали токенов на сотни и тысячи долларов. По данным Anthropic и нескольких разработчиков агентских харнессов, отдельные пользователи стабильно потребляли в 12–175 раз больше, чем стоимость их подписки.

С 15 июня программное потребление перестаёт субсидироваться общим пулом. SDK-запросы расходуются из выделенного кредита; ставки списания — те же, что и в публичном API. Когда кредит выработан, у пользователя два варианта: явно включить overage с биллингом по API-тарифам или дождаться следующего цикла.

## Почему именно сейчас

Anthropic это объясняет двумя факторами. Первый — финансовый: автономные агенты на длинных задачах съедают компьют, который компания не закладывала в экономику подписки. Второй — инфраструктурный: тот же GPU-инвентарь обслуживает интерактивных пользователей и фоновых агентов; без квоты второй класс вытесняет первый.

Есть и третий фактор, который Anthropic не озвучивает напрямую: OpenAI в эти же недели активно завоёвывает аудиторию агент-разработчиков. Если Anthropic не уравновесит экономику, он рискует субсидировать привычки сообщества, которое всё равно будет дрейфовать к платформе с более щедрым лимитом.

## Кого это бьёт сильнее всего

В первой группе — индивидуальные разработчики, привыкшие гонять `claude -p` в фоне на CI и локальных пайплайнах в режиме «работает 24/7». Для них $20 кредита на Pro эквивалентны примерно одному рабочему дню активного агента, после чего нужно либо платить overage, либо переключаться.

Во второй группе — компании, у которых GitHub Actions на Claude Code обслуживают десятки репозиториев на одной учётной записи. Раздавать по подписке на сервис не получится: $20 каждому сервисному аккаунту — это всё равно намного дешевле, чем оплачивать API напрямую, но архитектурно это требует ревизии.

В третьей — авторы агентских харнессов вроде OpenClaw. Anthropic фактически возвращает их в публичный API, где у Claude уже сейчас работают официальные SDK и rate-limit policies.

## Что это значит для рынка

Это первый раз, когда крупная LLM-лаборатория формально разделяет «человеческого» и «программного» потребителя на уровне биллинга. Скорее всего, аналогичная конструкция появится у OpenAI и Google в течение полугода: пока компании могли поглощать «утечку» подписок в агенты, они её терпели; как только Anthropic публично продемонстрировал, что от неё можно отказаться без бунта сообщества, остальные последуют.

Для самой Anthropic это шаг к более здоровой юнит-экономике подписочной части бизнеса. Для разработчиков агентов — стимул считать стоимость токенов, переходить на оптимизацию контекста, кэширование и более дешёвые модели в простых шагах. Для рынка инфраструктуры — толчок к слоям маршрутизации, которые умеют переключать агентов между провайдерами в зависимости от текущего кредита и стоимости.

## Что смотреть до 15 июня

Главное — какие коммьюнити-инструменты адаптируются первыми. На GitHub уже появились библиотеки-обёртки, считающие токены и переключающиеся на API-биллинг по правилам. Если до 15 июня выйдет популярный «бюджет-менеджер» для Claude Agent SDK, переход для большинства активных пользователей пройдёт безболезненно. Если нет — июнь обещает быть шумным.
