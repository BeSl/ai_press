11 мая Microsoft выкатил апрельский релиз Copilot Studio. Несмотря на скромное название «апрельские обновления», для корпоративных заказчиков это, возможно, важнейший апдейт квартала: в нём впервые сведены воедино средства администрирования агентов на масштабе всей компании.

## Что в релизе

Основная линия — agent governance. ИТ-администратор теперь видит каждого агента, развёрнутого в организации, по политикам, бюджетам и тегам — и может вводить ограничения по доступу, лимиты по токенам и правила тестирования до выкатки в продакшен. Параллельно появились:

- богаче «intelligent workflows» — конструктор автоматизаций с прямым подключением к Power Automate и сторонним коннекторам;
- «connected app experiences» в Copilot Chat — пользователь работает в одном чате, но агент при необходимости поднимает SharePoint, Salesforce, ServiceNow, не выходя из окна;
- расширенный usage estimator — прогноз ежемесячных расходов на агентов по сценарию и по департаменту, с учётом разной стоимости моделей;
- Work IQ preview — структурированная база знаний организации, на которую опираются агенты;
- agent-to-agent communication — стандартизированный канал, по которому один агент может вызывать другого через A2A-протокол.

## Почему это важно

В апреле Anthropic, Salesforce и Microsoft независимо друг от друга показали одну и ту же вещь: главный сдерживающий фактор корпоративного развёртывания агентов — не качество модели, а отсутствие предсказуемости. Финансовый директор не подпишет бюджет на сотню агентов, если он не понимает, во что это выльется в следующем квартале и кто отвечает за то, что один из них «сошёл с ума» и оформил тысячу заказов.

Copilot Studio переводит эту проблему в плоскость классического корпоративного администрирования: агент — это объект учётной политики, с бюджетом, владельцем и контрольными точками. Microsoft по сути продаёт не самих агентов, а инфраструктуру для агентов чужой и собственной разработки — это та же стратегия, что когда-то сделала Active Directory обязательной в каждой крупной компании.

## Что это значит для рынка

Apr-релиз Copilot Studio закрывает разрыв между «появилась платформа для агентов» и «появилась платформа, которой можно доверить квартальный бюджет». Для конкурентов это означает поднятие планки: следующие версии Google Agent Builder, Anthropic Agent Console и Salesforce Agentforce будут оцениваться не по количеству шаблонов, а по глубине governance-слоя.

Для покупателей же это сигнал к закупочному циклу. Anthropic в этом году впервые обогнал OpenAI по корпоративному ARR — Microsoft, очевидно, не намерен повторять эту историю на Copilot.
