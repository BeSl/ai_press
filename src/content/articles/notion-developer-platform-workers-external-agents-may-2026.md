Notion выпустила Developer Platform 3.5 — крупнейшее расширение программируемой поверхности продукта со времён публичного API 2021 года. Анонс прошёл на Dev Day 13 мая 2026 года и сразу же определил позицию компании в гонке корпоративных AI-агентов: не делать «своего лучшего ассистента», а стать местом, где работают агенты конкурентов.

## Три кирпича платформы

**Workers — хостинговый рантайм для произвольного кода.** Это управляемая среда выполнения внутри Notion: разработчик (или его coding-агент) пишет код, деплоит через CLI и запускает в защищённом sandbox-окружении. Workers слышат вебхуки, обращаются к внутренним и сторонним API, формируют ответы и сохраняют состояние в Notion-базах. На время беты Workers бесплатны; с 11 августа 2026 года их работа будет тарифицироваться кредитами Notion.

**External Agents API — приём чужих агентов как «своих».** API позволяет встраивать сторонних агентов в рабочее пространство Notion как полноценных собеседников. На старте заявлена работа «из коробки» с Claude Code, OpenAI Codex, Cursor и Decagon, плюс возможность подключить любой свой агент. Важно понимать асимметрию: classic SDK позволяет агентам Notion ходить наружу, а External Agents API — наоборот, впускает внешних агентов внутрь. Это инверсия привычной модели интеграций.

**Двусторонние вебхуки.** Раньше Notion мог только триггерить внешние сервисы; теперь любая внешняя система может вызвать Worker, который выполнит логику и обновит страницы, базы или комментарии. По сути это превращает Notion из «места хранения» в активного исполнителя бизнес-процессов.

Дополнительно в релиз вошли database sync (двусторонняя синхронизация баз с внешними источниками), новая система прав на блоки и API для управления Comments — но именно Workers и External Agents определяют стратегическую развилку.

## Что это значит для рынка

Главный сигнал — Notion отказался от модели «один продукт, один ассистент». Компания делает ставку на то, что AI-агентов в крупной организации будет много, они будут гетерогенными (Claude в продакте, Codex у инженеров, Cursor у платформенной команды, внутренний агент в HR) и им нужно общее операционное пространство. Развитие External Agents API — попытка занять это место раньше, чем его займут Slack (через AI Workflows), Microsoft 365 (через Copilot Studio) или ChatGPT с её Workspace Agents.

В практическом смысле External Agents API закрывает один из самых болезненных пробелов в корпоративном агентном стеке 2025–2026 — отсутствие «общей рабочей памяти» между агентами разных вендоров. Сегодня агент Claude, который читает спецификации, ничего не знает о том, что Codex в той же неделе закрыл связанный PR. Когда оба пишут в Notion как граждан первого класса, контекст склеивается на уровне страниц и баз, а не на уровне отдельных чатов.

## Цена и доступ

CLI и базовый доступ к API открыты на всех планах. Развёртывание и управление Workers — только на Business и Enterprise. External Agents API доступен в публичной бете для Business и Enterprise тарифов. Поддержка MCP заявлена как «приоритет ближайших месяцев»: Notion уже работает с Anthropic над тем, чтобы Workers стали полноценными MCP-серверами для всего Notion-пространства.

## Контекст недели

Анонс лёг в один ряд с другими событиями 13–15 мая 2026: OpenAI представила Workspace Agents и ChatGPT for Intune, Workday и Anthropic запустили акселератор для соло-предпринимателей, Freshworks показала AI Agent Studio, Five Eyes выпустил руководство по агентному AI. Все вместе они подтверждают одну тезу: корпоративный AI 2026 года — это не модель и не интерфейс, а инфраструктура агентного взаимодействия. Тот, кто получит контроль над протоколами и точками входа, заработает следующие $100 млрд капитализации.

## Что смотреть дальше

Ключевой вопрос — превратит ли Notion External Agents API в де-факто стандарт. Если в ближайший квартал к нему подключатся Microsoft Copilot, Salesforce Agentforce и Google Gemini Workspace — заявка на «контрольную комнату» сработает. Если крупные платформы предпочтут собственные закрытые форматы, Notion рискует остаться «нишевым хабом для разработчиков», а не точкой сборки корпоративных агентов. Ответ мы увидим уже к Notion Make 2026 в сентябре.
