Через неделю после общей доступности Gemini 3.1 Flash-Lite Google открыл верхний этаж стека — Gemini 3.1 Ultra. Это самый ёмкий релиз года у компании: окно контекста 2 млн токенов, единый нативный мультимодал и встроенный sandbox для исполнения кода прямо внутри ответа.

## Что нового по сути

Ключевая инженерная история — модель с самого старта тренировалась рассуждать по всем модальностям одновременно, а не склеивать их через транскрипцию. Раньше Gemini, как и почти все западные «мультимодальные» модели, под капотом всё равно сводил аудио и видео к тексту. В 3.1 Ultra текст, изображение, аудио и видео идут в одно reasoning-окно как единый поток. Это даёт двойной выигрыш: меньше потерь в задачах, где важна синхронизация (видеоаналитика, медицинские записи, инциденты безопасности), и заметно лучшее качество на длинных видео.

Окно в 2 млн токенов — теоретически достаточно, чтобы загрузить целую кодовую базу среднего стартапа или несколько часов аудио без чанкования. По внутренним бенчмаркам Google, точность на «иголке в стоге сена» на 1,8 млн токенов остаётся выше 96%, что заметно лучше предыдущей версии 3.0.

## Code Execution внутри ответа

Второй важный шаг — Code Execution Tool. Модель может написать, запустить и протестировать Python-код прямо в ходе разговора, в безопасной песочнице. По заявлению Google, это снижает галлюцинации на расчётных и аналитических задачах: вместо угадывания цифр модель выполняет код и подставляет реальный результат. Для разработчиков это де-факто встроенный мини-Jupyter, который не требует отдельной интеграции.

## Цены и доступ

Gemini 3.1 Ultra доступен через Gemini API в AI Studio и через Vertex AI для корпоративных клиентов с 13 мая. Цена входного токена держится в верхнем сегменте — Google не пытается конкурировать по стоимости, ставка идёт на «один вызов вместо пайплайна из трёх моделей». Параллельно модель встраивается в Gemini App и Workspace для тарифа Business — но с пониженным лимитом контекста, чтобы удержать unit-экономику массового продукта.

## Где это бьёт

Прямой удар — по Anthropic и OpenAI в трёх сегментах. Первый — длинные документы и юридические workflow: контекст в 2 млн токенов делает ненужными half-baked RAG-обвязки. Второй — мультимодальные агенты на видеосигнале (наблюдение, инциденты, спорт, медицина): нативный поток меняет себестоимость разработки. Третий — analytic agents, где Code Execution убирает целый класс ошибок при работе с табличными данными.

## Подводный камень

Окно в 2 млн токенов всё ещё дорого «в полную»: один такой вызов стоит больше десятка стандартных. Реальный эффект от релиза увидим через месяц-другой по двум маркерам — миграция корпоративных RAG-стэков на «без чанкования» и количество новых видеоаналитических SaaS-продуктов, которые сразу выйдут на Vertex AI поверх 3.1 Ultra.
