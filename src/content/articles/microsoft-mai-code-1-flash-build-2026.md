Microsoft 2 июня 2026 года на конференции Build анонсировала линейку собственных foundation-моделей MAI: рассуждающую MAI-Thinking-1 и коду-ассистента MAI-Code-1-Flash. Это первые крупные модели редмондского гиганта, разработанные полностью in-house без технологического стека OpenAI. Анонс — самый явный шаг Microsoft к снижению зависимости от партнёра, чьи модели до сих пор оставались ядром Copilot и Azure OpenAI Service.

## Что показали

MAI-Code-1-Flash — модель на 5 миллиардов параметров, оптимизированная под скорость и низкую стоимость токена. По бенчмаркам Microsoft, она обгоняет Claude Haiku 4.5 на всех четырёх ключевых coding-тестах, в том числе с разрывом 16 пунктов на SWE-Bench Pro (51,2% против 35,2%). На SWE-Bench Verified MAI-Code-1-Flash решает задачи аналогичной сложности на 60% меньшим объёмом токенов — что напрямую снижает счета за инференс.

MAI-Thinking-1 позиционируется как ответ на модели рассуждения OpenAI o-серии и DeepSeek-R1. Микрософт делает ставку не на максимальное качество, а на соотношение «цена/латентность»: модель развёрнута в Azure и заточена под промышленные пайплайны, где важнее предсказуемая стоимость, чем рекордные баллы.

## Стратегический сдвиг

До июня 2026 года Microsoft оставалась крупнейшим коммерческим потребителем технологий OpenAI: Azure OpenAI Service, Microsoft 365 Copilot, Bing и поверхности Windows работали поверх GPT-моделей. Соглашение между компаниями стало невзаимоисключающим ещё в мае, и MAI — первая публичная демонстрация того, что Редмонд намерен заместить ключевые слои стека собственными разработками.

GitHub Copilot — первая поверхность, в которую встраивается MAI-Code-1-Flash. Это означает, что миллионы запросов разработчиков, ранее уходивших в GPT, теперь будут обслуживаться внутренней моделью. Для Microsoft это означает экономию миллиардов долларов на партнёрских лицензиях; для OpenAI — потерю крупнейшего якорного клиента в сегменте coding.

## Что это значит для рынка

Появление MAI меняет конкурентную картину сразу на нескольких уровнях. Во-первых, Microsoft становится прямым конкурентом Anthropic и OpenAI в сегменте коду-моделей — самом доходном на сегодня направлении применения LLM. Во-вторых, Azure теперь предлагает заказчикам полный стек «первой стороны»: модели, инфраструктуру и инструменты разработчика без зависимости от третьих лиц. В-третьих, ценовое давление на Claude и GPT усиливается: если MAI-Code-1-Flash сравнима по качеству и дешевле, корпоративные заказчики получат рычаг в переговорах со всеми провайдерами.

Параллельно Microsoft на Build показала Scout Agent и Project Solara — компоненты агентской платформы, которые опираются на новые MAI-модели. Это часть более широкого тренда: 2026 год превращается из соревнования моделей в соревнование платформ, где побеждает тот, кто контролирует чип, рантайм, инструменты разработчика и слой безопасности одновременно.
